# جدّد — Jaddid

**تطبيق أندرويد وآيفون يذكّرك بتجديد مستنداتك الرسمية قبل انتهائها في دول الخليج الست، فتتجنب الغرامات وتعطّل المعاملات.**

الإقامة، الهوية، الجواز، رخصة القيادة، الاستمارة، تأمين السيارة، الفحص الدوري، التأمين الصحي، رخصة العمل، السجل التجاري، رخصة البلدية، عقد الإيجار — لك ولعائلتك وللعمالة المنزلية ولموظفي منشأتك.

---

## 💡 لماذا هذه الفكرة؟

| المشكلة | الحل في «جدّد» |
|---|---|
| ملايين المقيمين في الخليج مرتبطة حياتهم بمستندات لها تاريخ انتهاء (إقامة، تأمين، رخصة…) | لوحة واحدة تعرض كل المستندات مرتبة حسب الأقرب للانتهاء |
| التأخير يعني غرامات، وتوقف خدمات البنك والسفر، ومشاكل مع الكفيل أو صاحب العمل | تذكيرات قبل 60/30/14/7/3/1 يوم ويوم الانتهاء |
| رب الأسرة يتابع مستندات زوجته وأولاده والسائق والعاملة | كل الأشخاص في مكان واحد |
| المنشآت الصغيرة تتابع إقامات ورخص عمل موظفيها في ملفات Excel | باقة أعمال لمتابعة كل الموظفين |
| التواريخ في السعودية تُذكر كثيراً بالهجري | عرض التاريخ بالميلادي والهجري (أم القرى) |

**الميزة التنافسية:** لا يحتاج حساباً ولا إنترنت. البيانات تبقى على الجهاز، والتذكيرات محلية، فلا توجد تكلفة خوادم في البداية ولا مخاوف خصوصية.

## 💰 نموذج الربح

1. **اشتراك العائلة (Freemium):** مجاني حتى 5 مستندات، ثم 9.99 ر.س شهرياً أو 79 ر.س سنوياً.
2. **باقة الأعمال (B2B SaaS):** 99 ر.س شهرياً للمنشآت الصغيرة (حتى 50 موظفاً). هذا هو مصدر الربح الأكبر.
3. **عمولات الإحالة:** عند اقتراب انتهاء تأمين السيارة أو التأمين الصحي يظهر زر «قارن العروض» عبر شركاء التأمين، مقابل عمولة على كل وثيقة. السوق ضخم ومتكرر سنوياً.
4. **شراكات:** مراكز الفحص الدوري، ومكاتب التعقيب والخدمات العامة، ومكاتب استقدام العمالة.

**مثال تقديري:** 100 ألف مستخدم، منهم 3% مشتركون في باقة العائلة = 3,000 × 79 ر.س ≈ **237 ألف ر.س سنوياً**. يضاف إليها 200 منشأة × 99 × 12 ≈ **237 ألف ر.س سنوياً**، ثم عمولات التأمين.

## 🗺️ خارطة الطريق

- **الإصدار 1 (الحالي):** مستندات + تذكيرات محلية + هجري/ميلادي + 6 دول + واجهة عربية كاملة + وضع ليلي.
- **الإصدار 1.1:** الدفع داخل التطبيق (RevenueCat أو StoreKit / Google Play Billing) + نسخ احتياطي سحابي.
- **الإصدار 1.2:** تصوير المستند واستخراج تاريخ الانتهاء تلقائياً (OCR) + ويدجت للشاشة الرئيسية.
- **الإصدار 2:** لوحة ويب للمنشآت (ASP.NET Core API) + أكثر من مستخدم + تصدير Excel + تقارير.
- **الإصدار 2.1:** مقارنة عروض التأمين مع الشركاء + واجهة إنجليزية/أردية/هندية للعمالة.

## 📱 التقنية

- **Expo SDK 57 + React Native + TypeScript**: كود واحد يعمل على أندرويد وآيفون.
- **Expo Router** للتنقل (`src/app`).
- **expo-notifications** لتذكيرات محلية مجدولة الساعة 9 صباحاً.
- **AsyncStorage** لحفظ البيانات على الجهاز.
- واجهة عربية من اليمين لليسار (RTL)، ووضع ليلي، ودعم الشاشات الكبيرة.

```
src/
  app/            الشاشات: الرئيسية، إضافة/تعديل، التفاصيل، الاشتراك
  components/     مكونات الواجهة
  lib/            البيانات، التواريخ، التذكيرات، الحفظ
tests/            اختبارات منطق التواريخ
```

## ▶️ التشغيل

```bash
cd jaddid
npm install
npx expo start          # امسح الـ QR بتطبيق Expo Go على جوالك
npm test                # الاختبارات
npm run typecheck       # فحص الأنواع
```

> ملاحظة: الإشعارات في Expo Go على أندرويد محدودة، لذا جرّبها ببناء تطوير أو بناء معاينة.

## 🚀 النشر على المتاجر

```bash
npm i -g eas-cli
eas login
eas build --platform android --profile preview      # ملف APK للتجربة
eas build --platform all --profile production       # للنشر
eas submit --platform ios
eas submit --platform android
```

- **Google Play:** حساب مطوّر (25$ مرة واحدة) + نموذج أمان البيانات («لا يتم جمع بيانات»).
- **App Store:** حساب Apple Developer (99$ سنوياً) + بطاقة الخصوصية + تجربة عبر TestFlight أولاً.
- **تحسين الظهور في المتاجر (ASO):** العنوان «جدّد - تذكير تجديد الإقامة والمستندات»، وكلمات مفتاحية مثل: تجديد الإقامة، تذكير، أبشر، استمارة، تأمين، هوية مقيم.

> ⚠️ قبل النشر غيّر `bundleIdentifier` و`package` في `app.json` (حالياً `com.jaddid.app`) إلى معرّف تملكه.
