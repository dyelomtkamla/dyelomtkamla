## بدائل جاهزة
- **افتتاحية أقوى:** «نقل عفش بالشرقية؟ لا تشيل هم.»
- **سطر الخدمات (أقصر):** «فكّ، تغليف، نقل، وتخزين… كل شي علينا.»
- **ختام بديل:** «بروق الشرقية… سرعة، أمان، وسعر واضح. كلّمنا الحين!»

## ملاحظات نطق
- «ناوي» تُنطق *naawi* بمدّ خفيف · «فكّ» بتشديد واضح · «الحين» في النسخة البديلة = *al-ḥeen*.
- تجنّب الفصحى المتكلّفة: «نخدمك» وليس «نقوم بخدمتكم».
- اترك ٠٫٣ ثانية صمت قبل كل جملة — المونتاج مبني على هذه الفواصل.

## كيف تركّب الصوت على الفيديو
```bash
# ١) التعليق الصوتي فقط فوق الموسيقى الجاهزة
ffmpeg -i broog-ad-25s.mp4 -i voiceover.wav -filter_complex \
  "[0:a]volume=0.45[bed];[1:a]volume=1.0[vo];[bed][vo]amix=inputs=2:duration=first:dropout_transition=0[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k broog-ad-vo.mp4

# ٢) أو ابدأ من النسخة الصامتة واضف موسيقاك + صوتك
ffmpeg -i broog-ad-25s-silent.mp4 -i voiceover.wav -i music.mp3 -filter_complex \
  "[2:a]volume=0.35[bed];[1:a]volume=1.0[vo];[bed][vo]amix=inputs=2:duration=first[a]" \
  -map 0:v -map "[a]" -shortest -c:v copy -c:a aac -b:a 192k broog-ad-final.mp4
```
