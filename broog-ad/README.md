# إعلان بروق الشرقية — موشن جرافيك ٢٥ ثانية

إعلان كامل مبني بالكود (HTML/CSS/SVG + محرّك تايم-لاين حتمي) ويُصدَّر إلى MP4 بدقة 1920×1080 / 30fps،
مع موسيقى ومؤثرات صوتية مولَّدة برمجياً، ونص فويس أوفر خليجي جاهز للتسجيل.

## الملفات
| الملف | الوصف |
|------|-------|
| `broog-ad-25s.mp4` | **النسخة النهائية** (صورة + موسيقى ومؤثرات) |
| `broog-ad-25s-silent.mp4` | نسخة صامتة لتركيب موسيقاك وصوتك |
| `broog-ad-poster.jpg` | صورة الغلاف (Poster) |
| `voiceover-script.md` | نص الفويس أوفر الخليجي بالتوقيتات وتوجيه الأداء |
| `broog-ad.srt` | ترجمة/كابشن مطابق للتوقيتات |
| `scene.html` + `timeline.js` + `fonts.css` | مصدر الفيديو (قابل للتعديل والمعاينة بالمتصفح) |
| `render.mjs` | تصدير الإطارات عبر Playwright |
| `audio.py` | توليد الموسيقى والمؤثرات |
| `seo/VideoSection.cshtml` | قسم Razor جاهز لصفحة ASP.NET Core مع VideoObject JSON-LD |

## السيناريو (٦ مشاهد)
| الزمن | المشهد | المحتوى |
|-------|--------|---------|
| 0.0–3.6 | الخطّاف | «ناوي تنقل بيتك؟ وتخاف على أثاثك؟» + رموز الأثاث وعلامات الاستفهام |
| 3.5–7.4 | اللوجو | بناء شعار البرق داخل السداسي + «بروق الشرقية — لنقل وتخزين الأثاث» |

| 13.2–17.4 | التغطية | خريطة المنطقة الشرقية مع ٦ مدن ومسار متحرك |
| 17.4–21.0 | الثقة | عدّادات: +٥٠٠٠ عملية · ١٠٠٪ ضمان · ٢٤/٧ + شارات الثقة |
| 21.0–25.0 | النداء | الشعار + «اتصل الآن» + الرقم + «أثاثك يوصل بسرعة البرق» |

## تعديل البيانات (رقم الجوال مثلاً)
افتح `scene.html` وابحث عن `id="s6phone"` وغيّر الرقم، ثم أعد التصدير.
نفس الشيء لأي نص آخر — كل الكلام داخل HTML عادي.

## المعاينة والتصدير
```bash
# معاينة حيّة في المتصفح (حلقة تكرار)
python3 -m http.server 8080   # ثم افتح http://localhost:8080/scene.html

# تصدير الإطارات ثم بناء الفيديو
node render.mjs 30 frames
python3 audio.py music_bed.wav
ffmpeg -y -framerate 30 -i frames/%05d.png -i music_bed.wav \
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -movflags +faststart \
  -c:a aac -b:a 192k -shortest broog-ad-25s.mp4
```

## نسخ إضافية (سوشيال)
```bash
# ستوري / ريلز 1080×1920
ffmpeg -i broog-ad-25s.mp4 -vf "scale=1080:-2,pad=1080:1920:0:(1920-ih)/2:color=#050B1C" -c:a copy broog-ad-story.mp4
# مربع 1080×1080
ffmpeg -i broog-ad-25s.mp4 -vf "scale=1080:-2,pad=1080:1080:0:(1080-ih)/2:color=#050B1C" -c:a copy broog-ad-square.mp4
```
